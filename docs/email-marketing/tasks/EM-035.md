## Required behavior

1. Inbox/Mine/Needs action is the landing route. Inbox, Campaigns and More are the only main destinations; old deep links still work. Unassigned work has accountable coverage and a visible count. Role checks apply to More destinations and queries, not just menu visibility.
2. Implement08's exact work/outcome/controller facets and reason/next-action rows. Counts and paginated rows share server predicates and access scope; overlapping view totals are not summed. Loading, stale, errors and empty results remain distinct. Unsubscribed is directly findable without changing a restriction.
3. Own **INB-SAVEVIEW, INB-DELETEVIEW**: personal views, strict allowlist, query versions, RLS, ownership, update revisions and invalid-access handling. URL scope and Back survive thread/campaign navigation. Filtering/reading never changes controller, review, acknowledgment, campaign or Lead stage.
4. Campaign list handles simultaneous active/draft/paused/completed campaigns. Action count links to its exact inbox scope. Recipient selection is inside each campaign; saved lists remain under More with import/repair actions. Frozen active recipients cannot be silently replaced.
5. Sequence shows both complete messages, calendar-day wait, weekday window, actual date preview and termination. Draft edits invalidate review; existing approved cohorts remain pinned. Next send/hold comes from server evidence and shared capacity, never a guessed client date.
6. Reconcile all counts, source names, state labels, active-row scope and next-action links across inbox/campaign/CRM. Unknowns stay unknown. Preserve human takeover, suppression, frozen copy and no accidental phone/SMS/PPC effects.
